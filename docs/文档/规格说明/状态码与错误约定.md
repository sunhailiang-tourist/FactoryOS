> 关联：[编码绝对门禁](../架构/编码绝对门禁.md) · [Integration Studio](./Integration-Studio规格.md) · OpenAPI `FactoryOSError`

## 1. 双层模型

| 层 | 载体 | 职责 |
|----|------|------|
| **协议层** | HTTP 状态行（200/403/409/422/500…） | 监控、网关、重试、axios `response.ok` |
| **业务层** | JSON `code`（SCREAMING_SNAKE） | AC 断言、前端分支、审计、Runbook |

**硬规则**

- 失败 **禁止** HTTP 200 包装（REST `/v1/*`）
- body 禁止用 HTTP 数字当 `code`
- `http_default` 登记在 registry；`PlatformError(..., http_status=)` 可 override（方案 A）

## 2. 错误响应体（前后端共用）

```json
{
  "code": "AUTH_STUDIO_FORBIDDEN",
  "message": "Studio 访问被拒绝：当前角色无权限",
  "detail": "Studio 访问被拒绝：当前角色无权限",
  "details": { "role": "operator", "path": "/v1/studio/flows" },
  "trace_id": "01JXXX",
  "upstream": null
}
```

| 字段 | 必填 | 说明 |
|------|------|------|
| `code` | ✅ | 业务码 · registry 真源 |
| `message` | ✅ | 人读文案（可中文） |
| `detail` | ⭕ | **过渡期** = `message`；后续 deprecated |
| `details` | ⭕ | 字段级错误、role、Pydantic 数组等 |
| `trace_id` | ⭕ | 与 `X-Request-Id` 一致 |
| `upstream` | ⭕ | 第三方 `{ code, message }`（C→B 转义） |

**成功响应**：裸 JSON 资源，**不**套 `{ data }` envelope。

## 3. 前后端共享与同步（强制）

### 3.1 真源与镜像

```text
contracts/error-registry.yaml          ← 唯一 SSOT（code + message_zh）
        │
        ├─ mirror_python ──→ errors.py（ErrorCode + ERROR_MESSAGE_ZH + default_message）
        ├─ mirror_typescript → error-codes.ts（ERROR_CODES + ERROR_MESSAGES_ZH + getErrorMessageZh）
        └─（阶段 2）h5-worker 须同构 mirror
```

**硬规则（锁死）**

- 响应体：`code`（英文）+ `message`（中文，默认取 `message_zh`）
- 开发者调试：`format_error_label` / `formatErrorLabel` → `CODE · 中文`
- 门禁：`check_error_registry_sync.py` 校验 **code 与 message_zh** 双 mirror

| 字段 | 含义 |
|------|------|
| `mirror_python: true` | 必须出现在 `ErrorCode` enum + `ERROR_MESSAGE_ZH` |
| `mirror_typescript: true` | 必须出现在 `ERROR_CODES` + `ERROR_MESSAGES_ZH` |
| `message_zh` | **必填**（mirror 码）；API `message` 默认文案 · IDE JSDoc |
| `status: reserved` | 仅登记，不进 enum，直至启用 |

### 3.2 变更 SOP（缺一不可）

1. **只改** `contracts/error-registry.yaml`（增/改/删码或元数据）
2. 运行 `./scripts/check_error_registry_sync.py` — 查看 **ADD / DELETE / CHANGE** 报告
3. **负责人确认** 报告内容（Agent **禁止**擅自 `--apply`）
4. 确认后：`python scripts/sync_error_registry.py --apply`
5. 再跑 `check_error_registry_sync.py` 直至绿
6. 若改 handler/AC：同步本规约 · OpenAPI · 相关测试
7. `gate pr` 全绿

### 3.3 漂移门禁

| 命令 | 作用 |
|------|------|
| `check_error_registry_sync.py` | **硬门禁**：mirror 与 SSOT 不一致 → exit 1 |
| `sync_error_registry.py` | 默认 dry-run；`--apply` 写 enum/TS（须人工确认） |

**报告语义**

| 类型 | 含义 | 动作 |
|------|------|------|
| **ADD** | SSOT 有、mirror 无 | 确认后 `--apply` 或手工补 mirror |
| **DELETE** | mirror 有、SSOT 无 | 确认删码或恢复 registry |
| **CHANGE** | 元数据/日期提示 | 人工复核 http_default/message/handler |

## 4. 域前缀与 source

| 前缀 / 域 | source | 说明 |
|-----------|--------|------|
| 内核 11 码 | B | Gate 0 冻结名 |
| `AUTH_` | A | 用户/角色输入 |
| `VAL_` | A | 入参校验 |
| `REG_` | B | Registry / Studio 配置 |
| `INT_` | B | Integration 六步（reserved） |
| `EXT_` | C | ERP 转义 + `upstream` |
| `INTERNAL_` / `UNKNOWN_` | B | 兜底 |

`source` **不编进** code 字符串；仅运维分类。

## 5. HTTP 常用映射

| HTTP | 典型 code |
|------|-----------|
| 400 | `VAL_BAD_REQUEST` |
| 401 | `AUTH_ACTOR_MISSING`（reserved · 阶段 2） |
| 403 | `AUTH_STUDIO_FORBIDDEN` · `RULE_DENIED` · `INT_SHADOW_REQUIRED` |
| 404 | `REG_*_NOT_FOUND` · `REG_RESOURCE_NOT_FOUND` |
| 409 | `GRAPH_NOT_FROZEN` · `REG_CHANGE_REJECTED` |
| 422 | `VAL_SCHEMA_FAILED` · `MAPPING_ERROR` · `BLUEPRINT_INVALID` |
| 500 | `INTERNAL_ERROR` · `UNKNOWN_ERROR` |
| 502/503/504 | `CONNECTOR_ERROR` · `EXT_*` · `EDGE_OFFLINE` |

完整列表见 [`contracts/error-registry.yaml`](../../../contracts/error-registry.yaml)。

## 6. 前端约定（web-admin · h5-worker）

```typescript
import { ERROR_CODES, formatErrorLabel, getErrorMessageZh } from "@/api/request/error-codes";

// ApiError.code → 业务层英文码
// ApiError.message → 中文（服务端返回；缺失时 getErrorMessageZh 兜底）
formatErrorLabel(ERROR_CODES.AUTH_STUDIO_FORBIDDEN);
// → "AUTH_STUDIO_FORBIDDEN · Studio 访问被拒绝：当前角色无权限"
```

- Map 步失败：用 `MAPPING_ERROR`（**不**单独 `INT_MAP_INVALID`）
- Studio 无权限：`AUTH_STUDIO_FORBIDDEN` + `details.role`
