核心组件 (Packages)

graph_service

Graph 服务

业务流程图引擎，节点=步骤，边=流转；RDS 存储 + 版本号 + checksum 校验。

就绪 · CORE PLATFORM
rule_engine

Rule 引擎

规则集引擎，定义谁能在何条件下执行何动词；强制绑定 Graph Version。

就绪 · DECISION SYSTEM
execution_service

Execution 服务

执行引擎，维护 ExecutionEvidence，是系统唯一写路径的必经关口。

就绪 · ACTION CORE
audit_service

Audit 服务

审计日志引擎，记录全链路操作痕迹，支持对账与异常回溯。

就绪 · TRUST LAYER
connector_sdk

Connector 服务

连接器 SDK，通过 Blueprint 隔离协议细节，对接异构系统。

就绪 · GIP INTERFACE
agent_orchestrator

Agent 编排

意图识别中心，LiteLLM，将 Intent 转化为 DSL 执行计划。

待开发 · INTELLIGENCE
license_service

License 服务

租户 License 授权控制，精确到 Pack 和能力单元的生命周期管理。

就绪 · COMMERCIAL
mcp_gateway

MCP 网关

Model Context Protocol 网关，支持标准化外部协议转换与接入。

待开发 · CONNECTIVITY
platform_registry

平台注册表

PostgreSQL Registry DB + Studio publish；tenant_profiles、connector_instances、OverrideDocument、Pack 资产配置真源（ADR-008）。路径：src/server/os_core/platform_registry

D区 - 运行时唯一写路径

强制路径流程:

1. 用户请求 → Agent Orchestrator 意图识别 → DSL 计划

2. Harness 验证 (确认门：人工/规则通过)

3. Rule Engine 校验 (规则默认拒绝，白名单放行)

4. 记录 ExecutionEvidence (唯一写路径必经)

5. Connector 写入 Data-L0/L1

6. 对账 Job 验证一致性
