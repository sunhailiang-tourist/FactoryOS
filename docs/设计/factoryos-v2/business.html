第二家 Import 向导 (W-10)

Pack 三层可插拔模块体系

Pack-L1 | 流程模块

卖「业务场景」

Graph Pack：定义端到端的业务闭环，如“标准离散报工流程”、“精益质检流程”。

example: graph-report-v1.json

Pack-L2 | 能力模块

卖「能做什么」

Capability Pack：通用的 AI 或执行能力，如“语音识别报工”、“OCR 图片转单据”。

example: cap-voice-to-dsl.json

Pack-L3 | 连接模块

卖「接什么系统」

Connector Pack：异构系统的适配器，如“金蝶 Cloud 连接器”、“SAP Connector”。

example: conn-kingdee-write.json

收入层级 vs Pack 层级

收入层级 Pack 层级 卖什么 (销售口径)
L0 底座订阅 — SaaS 基座能力、多租户管理、审计存证
L1 场景包 Pack-L1 Graph Pack 端到端业务场景（如：标准服装厂报工包）
L2 能力包 Pack-L2 Capability Pack AI / 执行增强能力（如：语音转 DSL、智能纠错）
L3 连接器 Pack-L3 Connector Pack 异构系统对接（如：金蝶 Cloud Write 连接器）
Override 机制: 所有租户定制逻辑均通过 OverrideDocument 实现，经 Studio publish 生效，禁止手动修改通用 Pack JSON。
