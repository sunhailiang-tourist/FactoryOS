P01 · 产品定位

制造业智能中枢 Overlay — 不替代 ERP，提供敢写、可追、可回滚的执行层

✅ 我们是什么

  • ERP/MES 之上的 Governed AI 执行 Overlay
  • 冻结 Graph + Rule + 唯一写路径 + Audit + Revert

  • ERP 替代品 / 聊天机器人
  • Agent 直连数据库
  • 客户全量业务数据中台（默认）
