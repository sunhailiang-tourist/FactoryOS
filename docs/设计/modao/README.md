## 墨刀怎么建（产品流程稿）

1. 新建墨刀项目 → 用**流程图元件**（不是表单 UI）
2. 按 `Ax-OS-产品流程设计稿-v1.0.md` 篇章五建 **17 页**
3. 按 `墨刀-产品流程原型说明.md` §四 画热区连线
4. 分享链接给老板/实施/新人 — 打开即懂业务全貌
