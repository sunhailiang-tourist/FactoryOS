# 墨刀 · 产品流程原型搭建说明

> **本文档对应**：[`Ax-OS-产品流程设计稿-v1.0.md`](./Ax-OS-产品流程设计稿-v1.0.md)  
> **预览**：[`ax-os-product-flow-prototype.html`](./ax-os-product-flow-prototype.html)  
> **性质**：业务总体规划 · os_core 能力流 · 业务规划图 — **不是高保真 UI**

---

## 一、你要建的是什么

别人打开墨刀后应看到：

- 产品卖什么、不卖什么
- os_core 十模块怎么协作
- 第一家怎么接入、工人怎么报工
- 第二家怎么复制、怎么商业化

**不要**建：登录框、按钮、表单、KPI 卡片。

**要**建：流程图、架构图、决策树、时间轴、模块关系图。

---

## 二、墨刀项目设置

| 项 | 建议 |
|----|------|
| 项目名 | Ax OS · 产品流程设计稿 v1.0 |
| 画布 | **1920×1080** 或 **1440×900**（流程图够用即可） |
| 元件 | 矩形、菱形（判断）、箭头、泳道 |
| 配色 | 深蓝底 `#0c1018` · 节点 `#141c2e` · 强调 `#4db8e8` · Gate 用 `#e8b84d` |

## 三、17 页内容要点（复制到墨刀）

每页 = 一张**业务流程图**，底部放 2–4 个热区跳相关页。

| 页 | 标题 | 画布内容（画什么） |
|----|------|-------------------|
| P00 | 封面 | 标题 + 五条主路径入口按钮 |
| P01 | 产品定位 | 双栏：是什么/不是什么 + 双极图 |
| P02 | 客户分型 | 表格 A/B/C + 场景顺序箭头 |
| P03 | D1/D2 | 上下两框 + 五项机制标签 |
| P04 | 资产化飞轮 | 第一家→Package→第二家 import 循环 |
| P05 | 四平面 | 四层泳道 Control/Runtime/Config/External |
| P06 | os_core 十模块 | 3×3 卡片 + execution 居中加粗 |
| P07 | 唯一写路径 | 横向七步箭头链 |
| P08 | Path A/B/C | 三行对比表 |
| P09 | 数据 L0-L3 | 四层堆叠 |
| P10 | Gate 地图 | 一条长流程 + 人审 Gate 标黄 |
| P11 | Studio 六步 | 六格 + 每格一句业务问题 |
| P12 | 接入七步 | 纵向时间轴 Step0-7 |
| P13 | 报工闭环 | 工人→主管→ERP 循环 |
| P14 | 第二家复制 | 菱形判断 import / 全量 D1 |
| P15 | Pack 商业 | L1/L2/L3 三层 + 套餐表 |
| P16 | 研发分期 | Gate0→1a→1b→2→3 箭头 |
| P17 | 长期演进 | Stage1-4 阶梯 |

详细文案见 [`Ax-OS-产品流程设计稿-v1.0.md`](./Ax-OS-产品流程设计稿-v1.0.md)。

## 五、与 HTML 预览的关系

1. 打开 `ax-os-product-flow-prototype.html` **定内容与跳转逻辑**
2. 墨刀按同结构建 17 页（可截图 HTML 作参考底图，但建议用流程图元件重画以便编辑）
3. 评审用墨刀分享链接；研发/产品内部可继续用 HTML

---

## 六、与高保真原型的区分

| | 产品流程稿（本文） | UI 交互稿（ax-os-prototype.html） |
|--|-------------------|----------------------------------|
| 目的 | 讲清业务与架构 | 演示界面长什么样 |
| 读者 | 老板、新人、实施 | 设计、前端 |
| 墨刀画法 | 流程图、架构图 | 表单、侧栏、页面 |
| 是否必需 | **是，总体规划** | 研发阶段再用 |

---

## 七、演示话术（15 分钟）

1. **P01**（2min）：Overlay 不是 ERP，双极缺一不可  
2. **P05-P07**（4min）：四平面、os_core、写路径红线  
3. **P10-P12**（5min）：Gate、Studio 六步、首家七步  
4. **P13**（2min）：报工日常闭环  
5. **P14-P16**（2min）：复制、商业化、研发顺序
