## （可选）团队内再建 Project 文件夹

若希望文件不在 Drafts、而在 `Project: FactoryOS` 目录下：

1. 打开团队 **FactoryOS** → **New project** → 名称随意（如 `Ax-OS`）  
2. 对上面两个现行文件：**Move to project…**  
3. 把 Project 链接回贴，例如：

```text
FactoryOS Project：https://www.figma.com/files/project/<projectId>/...
```

收到后会更新 `FIGMA-FILE.md`，之后 `create_new_file` 带 `projectId`。
