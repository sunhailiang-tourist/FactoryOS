## 二、系统业务链路（墨刀必须理解的四条主线）

### 2.1 架构分层（L0 写路径 · 与 core/data 一致）

```text
用户/工人意图
  → Agent Orchestrator（意图 → DSL）
  → Harness 验证（规则默认拒绝，白名单放行）
  → Rule Engine（绑定已冻结 Graph 版本）
  → ExecutionEvidence 持久化（唯一写路径必经 · 在 Connector 前）
  → Connector SDK（写 Legacy 或 Builtin）
  → 对账 Job（Drift 检测）
  → Audit 事件（audit_service）
```

**红线**：Agent 禁止直写 DB；Shadow 期间为 **simulated ExecutionRecord**，不写真实 Legacy。

### 2.2 主线 A · 首家接入（UC-01 · 实施顾问）

```text
W-01 登录（含租户 ID）
 → W-02 首页 KPI
 → W-03 选租户「哈森」          ← 【缺失】
 → W-04 Connect（只读·禁写）
 → W-05 Discover（CMV 动词表）
 → W-06 Map（映射 + confidence） ← 【缺失内容】
 → W-07 Prove（Shadow≥14d · 双签 · 禁用态）
 → W-08 Freeze（G-FREEZE）      ← 【缺失内容】
 → W-09 Export（Package · 跳 H-01） ← 【缺失内容】
```

### 2.3 主线 B · 日常报工（UC-02 · Path A 灯塔）

```text
钉钉/企微 → h5_worker_entry（选角色）
 → H-01 home（当前工单）
 → H-02 语音/扫码/拍照/手动     ← 【缺扫码/手动】
 → H-03 confirm（Harness 确认卡）
 → H-04 success（仅「待主管审批」）← 【逻辑矛盾待修】
 → H-05 approve（主管待办）
 → H-06 批准/驳回
 → H-07 已写 ERP + 对账一致      ← 【缺失】
      └→ 返回管理台 W-02
```

**顶栏状态条（H-01～H-07 常驻 · 三态互斥）**

| 状态 | 文案 | 限制 |
|------|------|------|
| shadow_mode=true | ⚠️ 影子运行 · simulated only | 生产写禁用 |
| write_approved=false | 🔒 生产写未批准 | Connector 写禁用 |
| write_approved=true | ✅ 生产写已批准 | 正常闭环 |

### 2.4 主线 C · 第二家 Import（UC-03）

```text
W-10 Import
 → 选 Path 模板 / 源 Package
 → Override 差异
 → 【不可跳过】Connect 更新新客户凭证  ← 【缺失独立步】
 → 【不可跳过】Prove 双签             ← 【缺失独立步】
 → Workshop 差量（若有）
 → 部署上线
```

### 2.5 主线 D · Gate 三门（治理地图）

```text
正确顺序：
  G-FREEZE（图谱冻结）
    → G-SHADOW（≥14d · simulated · 对账）
      → G-WRITE-APPROVE（Prove 双签后开写）
        → Go-Live

现状 gate.html 卡片顺序：FREEZE → WRITE → SHADOW  ← 【错误】
shadow.html（W-11）内容正确，可作开写管控参考稿。
```

### 2.6 概念正交（最易学错 · 必须分开展示）

| 维度 A：写入路径 | 维度 B：部署隔离 |
|------------------|------------------|
| Path A：有 ERP，Connector 写 ERP | Pool：SaaS 多租户 · tenant_id + RLS |
| Path B：有 MES，MES 写 + ERP 读 | Bridge：**schema-per-tenant**（非私网桥） |
| Path C：无系统，Builtin 账本 | Silo：独立部署 cell |
| **哈森灯塔** = Path A + Pool + 钉钉，**无 MES** | Path 与 Pool **可组合**（免责说明保留） |

### 2.7 平台先行三阶段（strategy 必须照抄）

```text
Gate 0   底座可 Coding
阶段 1a  API 优先（os_core + Connector SDK）          ✅ 已完成
阶段 1b  Studio UI 浏览器联调                        ← 当前
阶段 2   h5-worker（UX-001）                         须 1a+1b 全绿后
阶段 3   哈森灯塔（Path A · 四 Gate）                  须 阶段2 全绿后
```

**禁止出现**：Phase 1c h5 · Stage2 Pack Registry · Stage3 进化层（与 PLATFORM-FIRST 冲突）。
